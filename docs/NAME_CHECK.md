# Name check: "Into the Frame"

Checked on 2026-11-16 by web search. **This is not a legal trademark clearance.** It is a first look for obvious clashes.

## What was checked, and how
Searches were run for the exact phrase "Into the Frame" alongside Google Play, the Apple App Store, Steam, Xbox, PlayStation, Nintendo, itch.io and trademark records. The stores' own search tools could not be queried directly from the working environment, which blocked those connections, so these results are from a general web search and **can miss listings**.

### Similar titles worth knowing
- ***Behind the Frame: The Finest Scenery*** (Silver Lining Studio, published by Akupara Games, 2021; on mobile, PC and consoles). It is also about an artist and painting, so it sits closest to us in subject and in the word "Frame". It is a different title, but it is the one a customer might confuse us with.
- ***Frame by Frame*** (a puzzle-platformer that steps into a film reel), ***Ephemeral Frame***, ***Out of Frame*** and ***MainFrames***. "Frame" is a crowded word in game titles.

## Reading the results
- **No exact match on any major store.** That is good, but the search is not exhaustive.
- **Two itch.io jam games share the exact name.** They are tiny, and itch.io is not a store we plan to publish on, but a trademark search could still show them.
- **"Into the Frame" is a common English phrase.** That makes it harder to register as a trademark, and a weaker mark if someone else uses something similar.
- **Using it as a series name with a distinct game title in front** (for example *Ye Tapestrie Adventures: Into the Frame*, or the series name only in the subtitle) is lower risk than making it the app's only title.

## What to do next (about an hour, by hand)
1. Search each store's own search box for "Into the Frame" in the US, UK and EU storefronts: Google Play, App Store, Steam, Xbox, PlayStation Store and Nintendo eShop.
2. Search the **USPTO** (tmsearch.uspto.gov) for "INTO THE FRAME", looking at Class 9 (downloadable game software) and Class 41 (online games and entertainment). Also search the **UK IPO** and **EUIPO** registers, since the games are UK-priced.
3. Check that a matching web domain and social handles are free.
4. If anything lives in Class 9 or 41, ask a trademark lawyer before printing the name on a store listing. **If the name is blocked, the fallback is "Masterpiece Leap"**, which was the runner-up.
5. Until it clears, use **each game's own title as the store name** and put the series name in the subtitle or description.
